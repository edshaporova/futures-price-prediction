# Торговая система на основе прогнозирования фьючерсов

## 1. Итоговая тема

Разработка торговой системы на основе прогнозирования временных рядов для определения точек входа и выхода по фьючерсам.

## 4. Краткое описание проекта

Цель проекта — разработать торговую систему, которая на основе исторических данных по фьючерсам будет прогнозировать их будущее движение и формировать сигналы для входа и выхода из позиции.

В качестве объектов исследования планируется использовать фьючерсы на валюты и акции/индексы.

В рамках проекта планируется собрать и подготовить данные, провести разведочный анализ, построить первые модели машинного обучения, реализовать ML-сервис, улучшить качество моделей, применить нейронные сети и провести финальное тестирование торговой системы.

Основной ожидаемый результат — рабочая система, которая получает данные по выбранному фьючерсу, формирует прогноз его будущего движения и на основе этого прогноза определяет торговый сигнал.

## 6. Этап 2: разведочный анализ данных (EDA)

**Инструмент:** квартальные фьючерсы на курс юань/рубль, серия `CR` (MOEX FORTS): 19 контрактов `CRM2` … `CRZ6`, 10-минутные свечи, апрель 2022 — ноябрь 2026, 247 тыс. свечей. Источник — MOEX ISS API.

**Ноутбук:** [`EDA_CNYRUB_futures.ipynb`](EDA_CNYRUB_futures.ipynb)

| Раздел ноутбука | Содержание |
|---|---|
| 1. Источник данных | Выгрузка с MOEX ISS (пагинация по 500 строк), даты экспирации |
| 2. EDA по каждому контракту | Качество данных, разрывы во времени, жизненный цикл ликвидности, переход ликвидности между контрактами, контанго, доходности и сезонность |
| 3. Единый временной ряд | Front-contract, roll gaps, back-adjusted ряд, индекс López de Prado |
| 4. Лог-доходности | Распределение, выбросы, стационарность (ADF/KPSS), ACF/PACF, кластеризация волатильности |
| 5. Target и признаки | Доходность через 10 минут, корреляции признаков |
| 6. Метрики и baseline | MAE, RMSE, R²_OOS, доля угаданных направлений, тест Диболда–Мариано; Zero, Persistence, AR(1), Ridge, RF, HistGB; стратегия с издержками |
| 7. Выводы | Итоги и рекомендации для следующих этапов |

### Основные выводы

- Данные чистые: нет пропущенных значений, дублей и ошибок OHLC; поле `value` всегда равно 0. Часть 10-минутных свечей отсутствует, потому что в эти интервалы не было сделок. У ближайшего контракта 98,8–100% шагов ровно 10 минут.
- 93,5% дневного объёма серии приходится на ближайший контракт. Ликвидность переходит на следующий контракт в последние 1–2 дня перед экспирацией.
- Устойчивое контанго (1,4–3,7% за квартал): при склейке контрактов возникают roll gaps (в среднем +2,5%), их нужно убирать.
- Лог-доходности стационарны и имеют тяжёлые хвосты (excess kurtosis ≈ 75). Волатильность сильно кластеризуется.
- ACF(1) ≈ −0,11 почти целиком создаётся режимом 2022 года; с осени 2022 г. она ≈ −0,02.
- На горизонте 10 минут ни одна модель значимо не превосходит нулевой прогноз. С учётом издержек сигнал направления неторгуем. Следующие шаги: более длинный горизонт, прогноз волатильности, внешние признаки.

### Как запустить

```bash
pip install -r requirements.txt
jupyter lab
```

Откройте `EDA_CNYRUB_futures.ipynb` и выберите **Kernel → Restart Kernel and Run All Cells** (около минуты). Сырые данные лежат в `data/raw/`. Чтобы скачать их заново с MOEX, поставьте `DOWNLOAD_FROM_MOEX = True` в ячейке настроек (5–10 минут).
