# Торговая система на основе прогнозирования фьючерсов

## 1. Итоговая тема

Разработка торговой системы на основе прогнозирования временных рядов для определения точек входа и выхода по фьючерсам.

## 4. Краткое описание проекта

Цель проекта — разработать торговую систему, которая на основе исторических данных по фьючерсам будет прогнозировать их будущее движение и формировать сигналы для входа и выхода из позиции.

В качестве объектов исследования планируется использовать фьючерсы на валюты и акции/индексы.

В рамках проекта планируется собрать и подготовить данные, провести разведочный анализ, построить первые модели машинного обучения, реализовать ML-сервис, улучшить качество моделей, применить нейронные сети и провести финальное тестирование торговой системы.

Основной ожидаемый результат — рабочая система, которая получает данные по выбранному фьючерсу, формирует прогноз его будущего движения и на основе этого прогноза определяет торговый сигнал.

## 5. План проекта

### 1. Старт и планирование
- Зафиксировать итоговую постановку задачи;
- Определить используемые фьючерсы;
- Определить прогнозируемую величину и правила формирования торгового сигнала;
- Оформить структуру проекта и GitHub-репозиторий.

### 2. Разведочный анализ данных (EDA)
- Собрать исторические данные по выбранным фьючерсам;
- Проверить качество и полноту данных;
- Исследовать динамику цен и доходностей;
- Подготовить данные для дальнейшего моделирования.

### 3. Первые ML-модели
- Построить первые модели прогнозирования;
- Сравнить качество полученных прогнозов;
- Сформировать базовые правила входа и выхода из позиции.

### 4. ML-сервис
- Объединить обработку данных и модель в единый pipeline;
- Реализовать получение прогноза для выбранного инструмента;
- Реализовать отображение торгового сигнала.

### Промежуточная защита проекта
- Представить собранные данные и результаты EDA;
- Показать первые модели и их качество;
- Продемонстрировать текущую версию ML-сервиса.

### 5. Улучшение ML-модели
- Улучшить признаки и параметры моделей;
- Провести сравнение моделей;
- Выбрать наиболее качественные варианты для торговой системы.

### 6. Нейронные сети
- Реализовать модель на основе нейронной сети;
- Сравнить её с ранее построенными ML-моделями;
- Проверить качество торговых сигналов.

### 7. Финальные доработки

- Доработать правила формирования точек входа и выхода;
